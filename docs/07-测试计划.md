# 测试计划

> 项目：东软灵犀 · 校园智能体（OpenHarmony 5.0 / ArkTS）
> 文档版本：v1.0
> 对应代码范围：`entry/src/main/ets`、`entry/src/test`、`entry/src/ohosTest`

## 一、测试目标

1. 验证核心链路可用：登录鉴权 → 知识圈/资讯浏览 → AI 对话 → 刷题与埋点 → 笔记发布 → 打卡。
2. 验证纯函数逻辑正确：表单校验、日期格式化、学习数据统计。
3. 验证异常场景可控：弱网、超时、登录失效、空数据、后端字段缺失。
4. 确认沉浸式布局在手机 / 平板 / 2in1 三类设备上的适配表现。

## 七、异常与边界

| 场景 | 构造方式 | 预期 |
| --- | --- | --- |
| 请求超时（10s） | Charles 断点延迟 | 提示超时，页面保留已有数据 |
| 网络断开 | 飞行模式 | 展示错误占位，恢复网络后重试成功 |
| 登录态过期 | 服务端返回 50 | 只弹一次提示，跳转登录页 |
| 数据为空 | Mock 空数组 | 展示空态，不出现 `undefined` |
| 字段缺失 | Mock 移除 `rows` | 不崩溃，按空处理 |
| 快速连点提交 | 连续点击 10 次 | 只提交一次，按钮进入防重复状态 |
| 图片加载失败 | 使用失效 URL | 展示兜底图 |

## 九、缺陷分级

| 级别 | 定义 | 处理要求 |
| --- | --- | --- |
| P0 致命 | 崩溃、白屏、主流程不可用、数据丢失 | 当轮修复 |
| P1 严重 | 主要功能异常、有明显错误提示缺失 | 当轮或下轮修复 |
| P2 一般 | 交互瑕疵、文案错误、次要入口异常 | 排期修复 |
| P3 轻微 | 视觉细节、极端场景 | 可选修复 |
