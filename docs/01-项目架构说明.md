# 东软灵犀 · 校园智能体 —— 项目架构说明

> 本文档描述当前仓库的整体分层、目录职责与关键数据流，供新同学快速上手与后续重构参考。
> 适用版本：OpenHarmony 5.0 / ArkTS / Stage 模型。

## 一、技术栈

| 维度 | 选型 |
| --- | --- |
| 操作系统 | OpenHarmony 5.0（compatibleSdkVersion 12） |
| 语言 | ArkTS（ArkUI 声明式范式） |
| 应用模型 | Stage 模型（UIAbility + WindowStage） |

| 可视化 | `@visactor/harmony-vchart`（玫瑰图 / 柱状图） |
| 日历 | `@ohmos/calendar` |
| Markdown | `@luvi/lv-markdown-in` |
| 测试 | `@ohos/hypium` + `@ohos/hamock` |

## 二、目录职责

```text
entry/src/main/ets
├── entryability/          # UIAbility 入口，负责创建窗口、开启沉浸式
├── entrybackupability/    # 备份恢复扩展
├── commons/               # 跨页面复用的基础设施
│   ├── components/        # 通用 UI 组件（骨架屏、瀑布流、导航栏、图表…）
│   ├── constants/         # 全局常量（事件名、路由、存储键）
│   └── utils/             # 非 UI 能力（请求、鉴权、埋点、日志、全屏…）
├── models/                # 数据模型
│   ├── index.ets          # 全局共享接口与枚举
│   ├── tempModel/
│   │   ├── DataModel/     # 业务实体（Message、Mindmap、TopicAI…）
│   │   └── Interface/     # 与服务端约定的请求/响应结构
│   └── LazyForeachResource/ # IDataSource 实现，供 LazyForEach 使用
├── pages/                 # 路由页面（需在 resources/base/profile/main_pages.json 注册）
└── views/                 # 页面的局部视图，按页面名建子目录
```

### 分层约定

1. **pages 只做编排**：负责读取路由参数、调用 utils 发请求、把数据下发给 views。
2. **views 只做展示**：通过 `@Prop` / `@Link` / `@ObjectLink` 接收父级数据，不直接发请求。
3. **commons 无业务语义**：`commons/utils` 与 `commons/components` 不允许 import `pages/` 或 `views/`。
4. **models 不依赖 UI**：仅包含 interface / enum / class，禁止 import `@kit.ArkUI`。

> 当前 `commons/components/NotesWaterFlow.ets` 直接 import 了 `pages/reEdit` 的 `noteIdParams`，
> 这是一处已知的层级倒置，后续应把该类型下沉到 `models/tempModel/Interface/`。

## 三、关键数据流

```text
UIAbility.onCreate
   └── AppStorage.setOrCreate('context', this.context)
UIAbility.onWindowStageCreate
   └── loadContent('pages/Index') → fullScreen.enabled()
        └── 写入 AppStorage: topHeight / bottomHeight
Index (Tabs)
   ├── HomePage        —— 首页：打卡、热圈、资讯速览、硬件控制入口
   ├── AIChatPage      —— AI 对话：知识圈 → 话题 → 会话
   ├── KnowledgeSphere —— 知识圈：CircleGrid + 今日资讯瀑布流
   └── MinePage        —— 个人中心：笔记、收藏、草稿
```

### 鉴权链路

```text
auth.initUser()                       # PersistentStorage.persistProp('user')
auth.CheckAuth(options | Function)    # 无 token 时跳登录，并把 return_url 透传
httpReq 请求拦截器                     # 统一注入 Authorization: Bearer <token> 与 uid
httpReq 响应拦截器                     # success!=true 时 reject；errorCode==50 清 token 并跳登录
```

### 埋点链路

```text
Answer.onPageHide / changeSubject
   └── tracking.record(chapterId, start, end, questionId, userAnswer)
        └── preferences('tracking-store') 本地累积
tracking.report(force)                # ≥5 条或强制时上报 /question/answerUpload
HomePage.aboutToAppear                # tracking.report(true) 兜底上报
```
